Le projet

Ce site est un exercice réalisé dans le cadre de mon cours de technologies web (IFOSUP, bloc 1). L'objectif n'est pas de produire un site parfait, mais de comprendre toute la chaîne : écrire des pages, les versionner avec Git, les envoyer sur GitHub, puis les publier.

Le code a été généré par une intelligence artificielle à partir de mes instructions. Je l'ai ensuite lu, testé et publié moi-même. Je le dis clairement ici : ce n'est pas du code écrit à la main.

Comment il a été créé

  1. Décrire ce que je veux

    J'écris une demande claire : le sujet, les technologies autorisées, le niveau de qualité attendu.

  2. Laisser l'IA générer le code

    Claude produit les fichiers index.html, style.css et script.js.

  3. Relire et tester

    J'ouvre la page dans mon navigateur et je vérifie que tout fonctionne, y compris sur téléphone.

  4. Versionner avec Git

    Je crée un commit, puis j'envoie le projet sur GitHub avec git push.

  5. Publier avec Vercel

    Vercel se connecte au dépôt GitHub et met le site en ligne à chaque mise à jour.

Ce que j'ai déjà appris

Envoyer le projet sur GitHub ne s'est pas fait du premier coup. Chaque erreur m'a appris quelque chose.

  • Erreur 403. Windows avait gardé les identifiants d'un ancien compte GitHub. Le droit de pousser dépend du compte connecté.
  • « src refspec main does not match any ». Le dossier était vide : sans fichier, il n'y a pas de commit à envoyer.
  • Refus « fast-forward ». Le dépôt GitHub contenait déjà un commit (le README). Il faut le récupérer avec git pull avant de pousser.
  • Auteur des commits. Le nom affiché vient de git config user.name, pas du compte connecté.

Questions fréquentes

Ce site est-il vraiment fait par une IA ?

Oui. Le code a été généré par Claude, un assistant d'Anthropic. Je l'ai relu, testé et publié.

Pourquoi utiliser une IA pour apprendre ?

Elle produit une base fonctionnelle que je peux lire, modifier et casser pour comprendre. Le but est de m'approprier le code, pas de le copier sans réfléchir.

Le site collecte-t-il des données ?

Non. Il n'y a ni formulaire, ni cookie, ni outil de statistiques. Seul le choix du thème clair ou sombre est mémorisé dans ton navigateur.

Puis-je réutiliser le code ?

Oui, à titre d'exemple. Le dépôt est public sur GitHub.
